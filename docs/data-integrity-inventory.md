# HisaFlow Dashboard Visuals — Data Integrity Inventory (Phase 0)

> Generated from full source audit of `apps/frontend` and `apps/backend` per `hisaflow-data-integrity-brief.md` Section 3.1.

## Legend
- **faithful**: Rendered strictly from backend records scoped by org, timezone, and range with honest zero/empty states.
- **suspect**: Reads backend data, but uses UTC/OS-local boundaries, pagination truncation (`take: 5`), hardcoded delta fallback (`+100%`), mixed definitions, or client-side range-unaware SWR `keepPreviousData`.
- **fabricated/fallback**: Contains hardcoded arrays, single-scalar multiplier sparklines, hardcoded comparison percentages, or placeholder/fallback rows shown as real data.
